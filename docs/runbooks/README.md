# Runbooks

This directory contains operational runbooks for the PM Agent system.

## Available Runbooks

- [Token Rotation](./token-rotation.md) - How to rotate API tokens and secrets

## Purpose

These runbooks provide step-by-step procedures for common operational tasks, incident response, and maintenance activities.

## Format

Each runbook should include:
- **Overview**: What the procedure accomplishes
- **Prerequisites**: What you need before starting
- **Steps**: Detailed step-by-step instructions
- **Verification**: How to confirm success
- **Rollback**: How to undo changes if needed
- **Troubleshooting**: Common issues and solutions
